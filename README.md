# Proyectos y Prácticas de Programación Orientada a Objetos (py)

Este repositorio recopila ejercicios y proyectos prácticos desarrollados durante el cursado de la materia Programación orientada a objetos de la Licenciatura en Ciencias de la Computación (UNSJ).

## Contenido
- **Tipos de Datos en Python: inmutables y mutables. Referencias en Python: Reference Counting. Pasajes de parámetros. Clases en Python. Tipo Abstracto de Datos. Creación de Objetos. Listas en Python (built-in List). Entrada salida de datos. Organización de programas en Python: módulos y paquetes. Arreglos NumPy. Procesamiento de archivos en formato libre (Comma-Separated Values). Funciones y métodos con parámetros por defecto. Constructores. Datos miembro estáticos y Funciones miembro estáticas. Sobrecarga de operadores. Destructores y recolección de basura.** 
- **Relaciones entre Clases en Python: Asociación, Clase Asociación, Clase que Modela Asociación, Agregación y Composición, Herencia y Herencia Múltiple. Polimorfismo: vinculación dinámica. Excepciones. Assert, Raise y bloque try- except-else-finally. Creación de nuevas clases excepción. Clase Lista definida por el programador como un nuevo contenedor. Iterador sobre la clase Lista definida por el programador. Clases Abstractas. Métodos Abstractos. Interfaces: Definición de
Interfaces. Implementación de Interfaces. Diccionarios en Python. Archivos JSON (JavaScript Object Notation).**

## Tecnologías utilizadas
- Lenguaje: Python
- IDE: Visual Studio Code
